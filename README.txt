SONORA — DUAL PLAYER

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder sonora-dual-player.
3. Buka index.html menggunakan Chrome atau Edge.
4. Pilih "Dengan Album" atau "Tanpa Album".
5. Klik tombol "Ganti tampilan" di kiri atas untuk kembali ke menu pilihan.

Struktur:
- index.html: halaman pilihan tampilan.
- modes/album.html: versi pemutar dengan album.
- modes/waveform.html: versi waveform tanpa album.

Catatan: Jalankan index.html, jangan langsung membuka file di folder modes jika ingin menu pilihan tampil.
Semua file berjalan lokal dan tidak memerlukan instalasi/build tools.
